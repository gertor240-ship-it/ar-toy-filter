# 🎄 AR Рождественская Лошадка-Качалка | WebAR Фильтр

Интерактивный WebAR опыт для примерки рождественской игрушки на реальной ёлке через браузер телефона.

## 🎯 Описание Проекта

Этот проект позволяет пользователям "примерить" 3D модель гипсовой лошадки-качалки с ручной росписью на свою рождественскую ёлку с помощью технологии дополненной реальности (AR) прямо в браузере.

### Особенности

- 🎨 **Красивый 3D дизайн**: Белая гипсовая лошадка с цветочными узорами
- 📱 **WebAR технология**: Работает в браузере без установки приложений
- 🎮 **Интерактивность**: Вращение и масштабирование модели жестами
- 🌟 **Современный UI**: Glassmorphism дизайн с анимациями
- 📸 **Marker-based AR**: Надежная работа на широком спектре устройств

## 🚀 Быстрый Старт

### Требования

- Node.js 18+ и npm
- Современный браузер (Chrome/Safari)
- Веб-камера для AR режима

### Установка

```bash
# Клонировать/скопировать проект
cd ar-toy-filter

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Приложение будет доступно на `http://localhost:5173`

## 🎮 Как Использовать

### Для Разработки

1. **Запустить сервер**: `npm run dev`
2. **Открыть в браузере**: `http://localhost:5173`
3. **Тестирование**:
   - Нажмите "Запустить AR"
   - Разрешите доступ к камере
   - Покажите камере AR маркер ([Hiro marker](https://github.com/jeromeetienne/AR.js/blob/master/data/images/hiro.png))
   - Наблюдайте 3D модель на маркере

### Для Конечных Пользователей

1. Отсканируйте QR-код на упаковке игрушки
2. Откроется страница в браузере
3. Нажмите "Запустить AR"
4. Разрешите доступ к камере
5. Наведите камеру на маркер (на упаковке или загрузите отдельно)
6. Взаимодействуйте с 3D моделью:
   - **Один палец**: вращение модели
   - **Два пальца**: масштабирование (pinch)

## 🐛 Troubleshooting

### Камера не работает

- **Разрешения**: Убедитесь, что браузер имеет доступ к камере
- **HTTPS**: Для продакшн требуется HTTPS (на localhost работает без HTTPS)
- **Браузер**: Используйте Chrome на Android или Safari на iOS

### Модель не загружается

- Проверьте путь к GLTF файлу в консоли
- Убедитесь, что `rocking_horse.gltf` находится в `public/models/`
- Очистите кэш браузера

### Низкая производительность

- Используйте устройство с хорошей графикой
- Закройте другие приложения
- Уменьшите качество освещения в настройках

### AR не обнаруживает маркер

- Убедитесь в хорошем освещении
- Держите маркер ровно перед камерой
- Маркер должен быть полностью виден в кадре

## 🎨 Кастомизация

### Изменение 3D модели

1. Создайте свою модель в Blender/Maya
2. Экспортируйте в формат GLTF 2.0
3. Замените `public/models/rocking_horse.gltf`
4. При необходимости обновите масштаб в `index.html`

### Изменение UI

- **Цвета**: Измените CSS переменные в `src/style.css`
- **Тексты**: Обновите в `index.html`
- **Логика**: Модифицируйте `src/main.js`
